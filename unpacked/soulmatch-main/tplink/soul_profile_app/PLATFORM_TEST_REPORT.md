## 推荐方案

### 混合模式（API + 截图）

```typescript
平台策略：
├─ 微博：API 抓取（完美）
├─ 网易云：API 抓取（完美）
├─ 小红书：截图 + GPT-4o 分析
├─ 抖音：截图 + GPT-4o 分析
├─ 豆瓣：截图 + GPT-4o 分析
└─ 知乎：添加 Cookie → 截图 + GPT-4o 分析
```

### 优势

1. **立即可用**
   - 微博和网易云已完美工作
   - 其他平台截图功能正常

2. **稳定可靠**
   - 不依赖易变的 API
   - 截图 + GPT-4o 视觉分析效果好

3. **维护简单**
   - 只需定期更新 Cookie
   - 不需要维护复杂的签名算法

4. **效果优秀**
   - GPT-4o 视觉分析能力强
   - 可以识别截图中的所有信息
