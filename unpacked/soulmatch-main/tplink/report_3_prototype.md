# 原型设计建议报告

> 基于问卷519份有效数据分析，结合会议讨论的产品方向，给出三个原型设计方向及优先级建议。

---

## 一、数据基础：用户最核心的需求信号

在设计原型之前，先梳理数据中最强的需求信号：

| 需求信号 | 数据支撑 |
|----------|----------|
| 想找同频朋友，而非单纯脱单 | 64.5% 首选「筛选三观同频的朋友」 |
| 聊天破冰是最大障碍 | 53.8% 社恐不会沟通，67.2% 需要接话建议 |
| 想要AI帮筛人，不想自己海选 | 39.3% 选模式B，60.7% 希望从多人里筛出值得聊的 |
| MBTI/性格是最易接受的入口 | 64.5% 愿意提供MBTI，50.4% 偏好AI辅助问卷注册 |
| 隐私是红线 | 73.0% 最不接受「自动抓取未授权内容」 |
| 想知道为什么合拍 | 49.5% 希望AI告诉他「我和对方为什么合拍」 |
| 希望提升自己的社交能力 | 68.6% 希望产品帮他提升表达和社交能力 |

## 二、三个推荐原型方向

---

### 原型A：「灵魂问卷 + AI破冰助手」
**定位**：轻量入门，最低门槛，聚焦社恐破冰痛点

#### 核心功能
1. **MBTI/灵魂问卷建档**：用3-5分钟的趣味问卷（含MBTI维度+三观题+兴趣标签）生成用户「灵魂档案」
2. **同频匹配推荐**：基于档案推荐同校/同城的同频用户，附上「你们合拍的理由」
3. **AI破冰助手**：开始聊天前，AI根据双方档案生成专属开场白；聊天卡壳时提供接话建议

#### 用户数据支撑

| 功能 | 数据依据 |
|------|----------|
| MBTI问卷建档 | 64.5% 愿意提供MBTI，50.4% 偏好AI辅助问卷注册 |
| 告知合拍理由 | 49.5% 希望AI说明合拍原因，83.8% 有推荐理由更愿意开口 |
| 破冰/接话建议 | 67.2% 需要接话建议，65.1% 需要基于对方特点的聊天建议 |
| AI生成开场白 | 43.4% 希望AI帮生成开场白 |

#### 设计要点
- 问卷设计要「有趣」而非「严肃」，借鉴MBTI的娱乐性包装，降低填写负担
- 「合拍理由」要具体可信（如「你们都喜欢深夜看纪录片，都讨厌无效寒暄」），而非泛泛的「性格相符」
- 破冰建议要基于对方档案个性化生成，不能是通用话术模板
- 隐私设计：仅收集用户主动填写的问卷内容，不读取任何手机数据

#### 适合冷启动原因
- 单人即可体验（填问卷→生成档案→看自己的「灵魂画像」），无需双端配对
- 3分钟完成注册，门槛极低
- MBTI话题本身在大学生中自带传播属性
- MVP只需：问卷系统 + 档案生成 + 基础推荐 + 聊天建议，技术复杂度低

#### 风险与规避
| 风险 | 规避方式 |
|------|----------|
| 档案不准确，建议失效 | 允许用户随时修改档案；建议加「不合适」反馈按钮 |
| 聊天建议太通用 | 每次建议需结合对方档案实时生成，不使用固定模板 |
| 冷启动用户少，匹配不到人 | 先做「档案展示」功能，允许用户看到彼此档案，不强依赖双向匹配 |

---

### 原型B：「AI分身深度筛选 + 真人接管」
**定位**：核心差异化，AI替用户完成初筛，只把「值得聊的人」推到用户面前

#### 核心功能
1. **AI分身养成**：通过多轮对话聊天训练AI分身（80.1%目标用户偏好），生成能代表用户性格的AI人格
2. **AI先行对话**：用户的AI分身与对方AI分身或真人先进行结构化对话，判断双方同频程度
3. **同频评分报告**：AI给出「匹配度报告」，说明双方在哪些维度合拍/不合拍
4. **真人接管**：双方AI判定同频后，推送给真人，真人在「已知对方大致性格」的前提下开始聊天

#### 用户数据支撑

| 功能 | 数据依据 |
|------|----------|
| AI分身养成 | 80.1% 目标用户偏好多轮对话养成方式 |
| AI替我筛选 | 39.3% 首选模式B，42.4% 目标用户选模式B |
| 深度判断三观同频 | 23.5% 希望AI深度判断三观同频 |
| 帮我避开难相处的人 | 28.1% 希望AI帮避开三观不合的人 |
| 识别对方是否真诚 | 28.7% 希望AI识别对方真诚度 |
| 从多人里筛出值得聊的 | 60.7% 希望AI从多人里筛出真正值得聊的 |

#### 设计要点
- AI分身养成过程要「沉浸有趣」，像养宠物或角色扮演，而非填表
- 匹配报告要有具体依据（「你们都倾向于慢热型相处，喜欢小圈子深度聊」），让用户信服
- 真人接管前，给用户看「对方的AI档案摘要」，降低破冰焦虑
- 明确告知用户「AI分身只在平台内运行，不会泄露到外部」，缓解隐私顾虑（75.5%最担心隐私泄露）
- 控制「分身聊得好、真人没话说」的风险（56.5%担心此问题）：真人接管时展示AI对话要点，帮助真人延续话题

#### 适合冷启动原因
- 差异化极强，市面上没有成熟竞品
- 用户好奇心驱动：「想看看AI分身是什么样的」本身就是拉新钩子
- 可先做「单人体验版」：用户训练分身后，让AI帮自己生成「社交说明书」，单人也有价值

#### 风险与规避
| 风险 | 规避方式 |
|------|----------|
| AI分身不像我，失去信任 | 提供「纠错」机制，用户可标注「这句话不像我」持续优化 |
| 用户担心AI替我说了什么 | 所有AI对话记录用户可查看，保持透明 |
| 技术复杂度高 | MVP阶段可简化为：AI分身=问卷档案，「AI对话」=基于档案的规则匹配，而非真正的LLM对话 |

### 原型C：「情境式破冰 + 社交成长」
**定位**：游戏化社交，通过共同体验（互动剧情/话题挑战）自然破冰，同时帮用户提升社交能力

#### 核心功能
1. **情境式破冰剧本**：两人匹配后，系统给出一个「共同话题剧本」（如：「你们都填了喜欢深夜散步，现在来聊一个深夜场景」），引导双方自然展开对话
2. **聊天复盘与成长**：每次对话后，AI给出「本次聊天亮点与卡壳点」分析，帮用户发现自己的社交问题
3. **社交能力提升模块**：针对用户的聊天短板，给出改进建议和练习（如「你常在对方讲完后没有回应，试试这个接话公式」）
4. **轻量约见推荐**：当双方聊天达到一定深度，系统推荐线下活动/见面场景

#### 用户数据支撑

| 功能 | 数据依据 |
|------|----------|
| 情境式破冰 | 42.6% 希望AI代替做初步破冰；65.1% 需要基于对方特点的聊天建议 |
| 聊天复盘 | 50.7% 希望AI帮复盘聊天效果 |
| 社交成长 | 68.6% 希望产品帮提升表达和社交能力（Q33最高项） |
| 帮总结自己社交问题 | 51.3% 希望AI帮总结自己在社交中的问题 |
| 推荐见面/约会场景 | 49.1% 希望产品推荐见面/活动场景 |

#### 设计要点
- 情境剧本要基于双方档案个性化生成，而非随机话题
- 复盘报告要正向鼓励为主，避免让用户觉得「被评判」
- 社交成长模块可单独作为功能存在，即使没有匹配到合适的人，用户也能从中获得价值
- 约见推荐要有具体场景（「附近有家适合你们聊读书的安静咖啡馆」），而非泛泛「要不要线下见面」

#### 适合冷启动原因
- 「社交成长」功能单人即可体验，不依赖双端匹配
- 68.6% 的用户希望提升社交能力，这是独立的强需求，可作为拉新钩子
- 游戏化设计自带传播：「AI给我的聊天复盘报告」容易形成社交分享

#### 风险与规避
| 风险 | 规避方式 |
|------|----------|
| 剧本感太强，聊天不真实 | 剧本只作为「话题引子」，不强制用户按剧本走 |
| 社交复盘让用户自卑 | 措辞正向化，突出亮点，改进建议以「尝试」而非「你做错了」表达 |
| 功能太多，MVP失焦 | 先只做「情境破冰+接话建议」，复盘和成长作为二期功能 |

## 三、三个原型方向对比

| 维度 | 原型A：灵魂问卷+破冰 | 原型B：AI分身深度筛选 | 原型C：情境破冰+成长 |
|------|----------------------|----------------------|----------------------|
| 核心价值 | 同频匹配+降低破冰门槛 | AI替我筛人，只聊值得的 | 游戏化破冰+提升社交能力 |
| 用户需求命中率 | 高（67%+用户需要破冰辅助） | 高（39%首选+30%愿意体验B） | 中高（68.6%想提升社交能力） |
| MVP复杂度 | 低（问卷+规则匹配+提示词） | 中（需LLM对话+档案系统） | 中（需对话分析+复盘生成） |
| 冷启动友好度 | 极高（单人可体验） | 高（单人可训练分身） | 高（单人可用社交成长） |
| 差异化程度 | 中（市面有类似产品） | 极高（无成熟竞品） | 高（成长维度独特） |
| 迭代速度 | 快（以天为单位可调整） | 中（分身质量需积累） | 快（话题库可快速扩充） |
| 推荐优先级 | **★★★ 首选MVP** | **★★★ 核心差异化** | **★★ 二期扩展** |

## 四、用户最担心的风险（设计红线）

以下问题在设计时必须提前规避，否则会严重影响留存：

| 风险 | 占比 | 设计应对 |
|------|------|----------|
| 隐私泄露/盗号 | 75.5% | 只收集主动授权内容；数据加密；明示隐私政策 |
| 分身说话不像我/社死 | 63.6% | 提供纠错机制；AI建议标注「仅供参考」；用户可一键关闭AI辅助 |
| 分身聊得好真人没话说 | 56.5% | 真人接管前展示AI对话摘要；AI主动帮真人「接棒」延续话题 |
| 读取手机相册/聊天记录 | 54%+ | 产品内永远不申请此类权限，并在注册时明确告知 |

## 五、冷启动策略建议

基于问卷数据，推荐以下冷启动路径：

**第一步：单人可用的「灵魂档案」**
- 用户填写MBTI问卷+兴趣爱好+三观题，生成专属「灵魂档案卡」
- 档案卡可分享到朋友圈/微信群（「看看AI怎么描述我」），利用MBTI话题自传播
- 目标：冷启动期通过分享裂变积累用户，无需双端配对即有价值

**第二步：同校优先匹配**
- 早期优先在单一高校内推广，确保匹配密度足够（29.9%用户偏好同校推荐）
- 可通过班级群、社团群、学生会定向投放

**第三步：以「破冰成功率」为核心指标**
- 不以「匹配数量」而以「第一句话回复率」和「对话持续时长」衡量产品效果
- AI破冰建议好用→用户愿意分享→自然口碑传播

## 六、付费点设计建议

| 付费功能 | 定价建议 | 数据支撑 |
|----------|----------|----------|
| 基础会员（更多匹配次数+基础破冰建议） | 3-8元/月 | 42.8%接受此档位 |
| 高级会员（AI分身深度养成+完整匹配报告） | 9-18元/月 | 27.4%接受此档位 |
| 旗舰会员（无限匹配+聊天复盘+社交成长） | 20元+/月 | 15.8%接受此档位 |

**免费层设计**：让用户免费体验「生成灵魂档案」和「查看1个匹配推荐」，付费解锁更多匹配和AI辅助功能。86%的用户愿意付费，免费层的目的是建立信任而非永久免费。

## 七、推荐 MVP 方案

结合会议要求（能以天为单位迭代的最小原型）和问卷数据，推荐以**原型A为基础、融入原型B的核心差异化**：

### MVP 功能清单（优先级排序）

| 优先级 | 功能 | 说明 |
|--------|------|------|
| P0 | MBTI+兴趣问卷建档 | 3分钟完成，生成灵魂档案卡 |
| P0 | 档案卡分享 | 可分享朋友圈，冷启动裂变 |
| P0 | 同频用户推荐 + 合拍理由 | 告知「为什么推荐这个人」 |
| P0 | AI接话建议 | 聊天卡壳时一键获取建议 |
| P1 | AI破冰开场白生成 | 基于对方档案生成专属开场白 |
| P1 | 聊天时基于对方特点的建议 | 实时辅助，而非通用话术 |
| P2 | AI分身养成（多轮对话） | 二期功能，提升分身准确度 |
| P2 | 聊天复盘报告 | 二期功能，提升用户社交能力 |

### 迭代验证指标

- **Day 1**：档案完成率 > 70%（说明问卷不让人觉得麻烦）
- **Day 3**：推荐点击率 > 40%（说明合拍理由有吸引力）
- **Day 7**：破冰建议使用率 > 50%（说明AI建议有效）
- **Day 14**：次周留存率 > 30%（说明产品产生持续价值）
- **核心指标**：两周内，是否有用户主动表示「愿意付费」或「推荐给朋友」
