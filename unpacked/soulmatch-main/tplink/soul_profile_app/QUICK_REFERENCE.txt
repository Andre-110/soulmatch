│ 📋 快速开始                                                   │
└───────────────────────────────────────────────────────────────┘

  1️⃣  进入项目目录
      cd /home/ecs-user/tplink-app/tplink/soul_profile_app

  2️⃣  运行交互式菜单

  3️⃣  选择操作
      1 - 登录小红书
      2 - 登录抖音
      3 - 刷新所有 Cookie
      4 - 检查 Cookie 健康状态

┌───────────────────────────────────────────────────────────────┐
│ 🔧 常用命令                                                   │
└───────────────────────────────────────────────────────────────┘

  登录平台
  ├─ 小红书:  npx tsx scripts/login-platform.ts xhs
  └─ 抖音:    npx tsx scripts/login-platform.ts douyin

  刷新 Cookie
  ├─ 单个:    npx tsx scripts/refresh-cookies.ts xhs
  └─ 所有:    npx tsx scripts/refresh-cookies.ts all

  健康检查
  └─ 检查:    npx tsx scripts/check-cookie-health.ts

┌───────────────────────────────────────────────────────────────┐
│ ⏰ 自动维护（Crontab）                                        │
└───────────────────────────────────────────────────────────────┘

  编辑定时任务
  └─ crontab -e

  添加以下行
  ├─ 每天凌晨 3 点刷新 Cookie:
  │  0 3 * * * cd /home/ecs-user/tplink-app/tplink/soul_profile_app && \
  │    npx tsx scripts/refresh-cookies.ts all >> /tmp/cookie-refresh.log 2>&1
  │
  └─ 每天早上 9 点健康检查:
     0 9 * * * cd /home/ecs-user/tplink-app/tplink/soul_profile_app && \
       npx tsx scripts/check-cookie-health.ts >> /tmp/cookie-health.log 2>&1

┌───────────────────────────────────────────────────────────────┐
│ 📊 监控日志                                                   │
└───────────────────────────────────────────────────────────────┘

  查看刷新日志
  └─ tail -f /tmp/cookie-refresh.log

  查看健康检查日志
  └─ tail -f /tmp/cookie-health.log

┌───────────────────────────────────────────────────────────────┐
│ 🛠️  故障排查                                                  │
└───────────────────────────────────────────────────────────────┘

  问题: 浏览器无法启动
  └─ 解决: sudo apt install google-chrome-stable

  问题: Cookie 刷新失败
  └─ 解决: npx tsx scripts/login-platform.ts xhs

  问题: 抓取数据失败
  ├─ 检查: npx tsx scripts/check-cookie-health.ts
  └─ 修复: npx tsx scripts/login-platform.ts xhs

  问题: Cookie 文件不存在
  └─ 解决: mkdir -p /home/ecs-user/cookies

┌───────────────────────────────────────────────────────────────┐
│ 🎯 工作流程                                                   │
└───────────────────────────────────────────────────────────────┘

  1. 初次登录
     └─ npx tsx scripts/login-platform.ts xhs
        └─ 在浏览器中完成登录
           └─ 按回车保存 Cookie

  2. 用户使用
     └─ 用户提供平台 ID
        └─ 系统读取 Cookie
           └─ 访问平台 API
              └─ 返回主页数据

  3. 自动维护
     └─ 定时刷新 Cookie（每天凌晨 3 点）
        └─ 健康检查（每天早上 9 点）
           └─ 发现问题 → 告警 → 重新登录
