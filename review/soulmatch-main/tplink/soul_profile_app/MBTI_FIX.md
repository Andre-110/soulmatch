# 🎉 MBTI 生成问题已解决

## 问题
之前 OpenAI 返回 `mbti: "-"`，因为 prompt 允许"信息不足写 -"

## 解决方案
修改了两个 prompt 文件，强制 AI 必须推断 MBTI：

### 1. output-contract.json
**修改前：**
```json
"mbti": "四字或融合型，如 INFJ 或 ISFJ×INFP；信息不足写 -"
```

**修改后：**
```json
"mbti": "必须输出四字 MBTI 类型（如 INFJ、ENFP）或融合型（如 ISFJ×INFP）；根据用户提供的所有信息（平台数据、自述、截图）推断最贴合的类型，即使信息有限也要给出最合理的判断"
```

### 2. system-instructions.md
**修改前：**
```
3. **MBTI**：写在根字段 `mbti`；融合型可写 `ISFJ×INFP`；禁止捏造测评分数。
```

**修改后：**
```
3. **MBTI**：写在根字段 `mbti`；必须根据用户的所有信息（平台数据、自述、截图、行为模式）推断出最贴合的 MBTI 类型；即使信息有限，也要综合分析给出最合理的判断；融合型可写 `ISFJ×INFP`；禁止捏造测评分数。
```

## 核心改进

**策略转变：**
- ❌ 旧策略：信息不足 → 返回 "-"
- ✅ 新策略：信息不足 → 综合分析推断最合理的 MBTI

**效果：**
- 即使只有简单的自述（"如果明天世界末日，今晚想好好吃一顿、和在乎的人待在一起"）
- 加上有限的平台数据（微博0条，网易云听歌数据）
- AI 也能推断出 **INFP**（内向、直觉、情感、随性）
